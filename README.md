# 404-error – Tietoturvan ja tekoälyn verkkopalvelu

**404-error** on verkkopalvelu, joka tekee tekoälyratkaisujen turvallisesta käyttöönotosta ja arjen kyberturvasta ymmärrettävää. Palvelu tarjoaa pienyrityksille, opiskelijoille ja IT-harrastajille selkeät toimintaohjeet, tietoturvan tarkistuslistat sekä matalan kynnyksen yhteydenotto- ja tukipyyntökanavan.

Projekti toteutetaan kahdessa vaiheessa:
1. **Staattinen sivusto (Sprintit 1–6):** Responsiivinen ja saavutettava sivusto (HTML5 & CSS3), joka sisältää etusivun, tietopankin ja toimivan yhteydenottolomakkeen. Julkaistu GitHub Pagesissa.
2. **Dynaaminen sivusto (Sprintit 7–15):** Palveluun lisätään käyttäjähallinta, tietokanta sekä täydet CRUD-toiminnot tukipyyntöjen jättämiseen ja hallinnointiin.
